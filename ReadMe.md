# High Definition Overview

The main purpose of this project is create a camera that is able to capture high resolution images; offering an alternative to traditional high-end expensive cameras. By having a linear image sensor travel across a scene capturing individuals frames, we should be able to mimic the output of traidtional high-end cameras that have large image dies. The main disadventage of this technique is its inability capture dynamic scenes, as any movement during the 'scanning' of a scene would result in visible distortion.
